# Menu photographs

These licensed Pexels photographs are temporary visual stand-ins, cropped to 320 × 320.
Replace them with RestoSphere's photographs of the corresponding dishes before production use.
No external image request is made by the application; the JPEGs are bundled for offline use.
Kitchen Web serves copies from `public/kitchen/menu/` (same files as `restosphere-fe-mobile/assets/images/menu/`).
Drinks without a photo (Nước suối) show a neutral icon instead.
